# 🛍️ Day 2 — FashionMart Retail Performance Dashboard

## 📌 Project Overview

This project is part of my Data Analytics learning journey.
After completing **Day 1 (basic Excel analysis)**, I advanced to building a **complete retail performance dashboard** using real-world business scenarios.

The goal was to analyze store performance, category trends, and profitability across regions.

---

## 🚀 Learning Progression

### 🔹 Day 1 — Foundation

* Basic Excel operations
* Data cleaning
* Conditional logic (IF statements)
* Basic KPIs (Total Sales, Average Order Value)
* Intro to simple analysis

---

### 🔹 Day 2 — Advanced Analysis (This Project)

* Data enrichment using **VLOOKUP**
* Combining multiple datasets (Sales, Products, Stores)
* Building **Pivot Tables for multi-dimensional analysis**
* Adding **Slicers for interactivity**
* Creating **Calculated Fields (Profit Margin)**
* Designing a **clean dashboard layout**

## 🛠️ Data Preparation

* Used **VLOOKUP** to:

  * Pull Product Name & Category from Product sheet
  * Pull City & Region from Store sheet

* Ensured:

  * No missing values
  * Consistent formatting
  * Correct data types

---

## 📈 Analysis Performed

### 🔹 Pivot Table 1

**Category vs Month**

* Metric: Sum of Revenue
* Purpose: Identify top-performing product categories over time

---

### 🔹 Pivot Table 2

**Region vs Store**

* Metrics:

  * Sum of Profit
  * Count of Transactions
* Purpose: Evaluate store and regional performance

---

### 🔹 Calculated Metric

**Profit Margin (%)**

```plaintext
Profit / Revenue
```

---

## 🎛️ Dashboard Features

* Interactive **Slicers**:

  * Date
  * Region

* Clean layout:

```plaintext
Slicers → Top  
Pivot Tables → Center  
Insights → Bottom  
```

---

## 🔍 Key Insights

1. **Clothing category** consistently generates the highest revenue across all months, indicating strong customer demand.

2. **South region stores** outperform others in total profit, making it the most valuable region.

3. **Profit margins remain stable (~20%)**, suggesting consistent pricing and cost control across stores.
