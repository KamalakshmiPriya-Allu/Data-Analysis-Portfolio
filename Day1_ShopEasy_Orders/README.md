# 📊 ShopEasy — Monthly Order Analysis

## 🔹 Problem Statement

Analyze 50 e-commerce orders to identify top-performing cities, average order value, and high-value transactions.

---

## 🔹 Dataset

* 50 orders
* Columns: Order_ID, Date, City, Product_Category, Sales_Amount, Profit, Order_Size

---

## 🔹 Steps Performed

* Created structured dataset in Excel
* Generated Profit column
* Applied IF formula to classify orders (> ₹30,000)
* Calculated KPIs: Total Sales, Total Profit, Average Order Value
* Used COUNTIF to analyze orders by city
* Applied conditional formatting for profit visualization
* Built bar chart (City vs Order Count)
